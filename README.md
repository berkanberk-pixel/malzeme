# Malzeme Depo Dashboard

Bu repo, malzeme stoklari, depo doluluklari ve depolar arasi hareketleri tek ekranda izlemek
icin hazirlanmis statik bir dashboard prototipi icerir.

## Ozellikler

- Koyu mavi/neon veri paneli tasarimi
- Malzeme, depo doluluk, gunluk hareket ve kritik stok KPI kartlari
- Depo bazli filtreleme
- Depolar arasi transfer akisi
- Oncelikli malzeme stok tablosu
- Haftalik giris/cikis grafigi
- Responsive tek sayfa HTML/CSS/JS yapi

## Calistirma

Projeyi herhangi bir statik dosya sunucusu ile acabilirsiniz:

```bash
python3 -m http.server 8000
```

Ardindan tarayicida `http://localhost:8000` adresini ziyaret edin.
